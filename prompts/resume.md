# 새 세션에서 이어가기

Career Evidence 개발을 현재 상태에서 이어가줘.

1. CLAUDE.md, DECISIONS.md의 현재 결정, docs/state/PROGRESS.md, HANDOFF.md, docs/CODEMAP.md를 읽어줘.
2. Git 상태와 실제 변경을 확인하고 사용자 작업을 보존해줘. HANDOFF의 설명과 실제 코드가 다르면 증거로 현재 상태를 정정해줘.
3. 현재 제품·API 기준은 v0.7, 개발 운영은 1인 v0.9야. 개발자가 전체 개발을 맡고 협업자 검수는 선택이야. archive의 예전 첫 과업이나 합성 전용 범위를 다시 적용하지 말아줘.
4. `docs/solo/TASKBOARD.md`와 HANDOFF를 대조해 다음 한 작업의 프롬프트와 필요한 계약만 읽고, 이미 완료한 부분을 재사용해 미완료 사용자 흐름을 구현·검증해줘.
5. 이력서 기반 검색, 대화형 문서 수정, 제출본 보존, 정책 범위의 자동 지원이라는 연결을 유지해줘.
6. 실제 실행 결과를 보고하고 PROGRESS·HANDOFF를 갱신해줘. 코드 위치·결정이 바뀌면 CODEMAP·DECISIONS도 맞춰줘.

현재 범위 안의 로컬 수정은 계획에서 멈추지 말고 진행해줘. 새 외부 실행이 필요하면 기존 요청·승인·계정·정책 범위를 먼저 확인하고, 이미 허용된 작업에 반복 확인을 요구하지 말아줘.
