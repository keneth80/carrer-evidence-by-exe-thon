# 로컬 시연 실행 안내 (S08 로컬분, 제출 없음)

기준일: 2026-11-18. 이 문서는 **지금 실제로 구현·실행한 범위**만 다룬다. 시연 구성 제안은 [DEMO_PLAN.md](DEMO_PLAN.md)를 본다.

## 1. 실행

```bash
npm ci                    # 처음 한 번
npm run build
node scripts/demo.mjs     # 4310·4311이 비어 있어야 한다. --keep이면 종료 후 임시 DB를 남긴다
```

`scripts/demo.mjs`의 동작:

1. 새 임시 DB로 개발 서버(API·웹·worker)를 띄운다.
2. 합성 이력서 `fixtures/resumes/frontend.synthetic.pdf`를 실제 API 경로로 통과시킨다. 경로는 업로드 → 추출 확인 → 확정 경력 → mock 검색 → 맞춤 이력서 확정·PDF → 지원서 → 폼 입력 확인이다. 이 단계는 `scripts/demo-seed.mjs`가 맡는다.
3. **제출 직전**에서 멈추고 화면 주소를 출력한다.

화면에서 할 일:

1. `http://127.0.0.1:4310/start`에서 사용자 이름 `demo`로 연결한다.
2. 출력된 지원서 화면에서 '폼 입력 확인됨'과 '3. 최종 확인과 제출 승인'을 보여 준다. **'승인하고 제출'은 누르지 않는다.**
3. 같은 화면의 '이 지원을 기준으로 비슷한 공고 찾기'를 누른다. 모드는 '서류 자동 준비(제출 없음)'으로 두고 설정을 저장한 뒤 hash 확인·동의 → 시작을 진행한다. 결과는 유사 공고 대기함에 나온다.
4. 처음부터 보여 주려면 `/start`에서 `fixtures/resumes/`의 합성 PDF를 새로 올린다.

Chrome 확장 경로를 창으로 보려면 `node scripts/chrome-apply-e2e.mjs --headful`을 실행한다. 이 경로도 제출 직전까지만 진행한다.

## 3. 시연 중 제출 방지

- `scripts/demo.mjs`, `scripts/demo-seed.mjs`, `scripts/chrome-apply-e2e.mjs`는 기본으로 승인·제출을 하지 않는다. 로컬 자체 폼 제출은 `--submit-local`을 붙일 때만 한다(DECISIONS S6-13).
- 실제 기업 사이트로 접속하거나 전송하는 코드 경로는 없다. 외부 사이트 실행은 `BROWSER_APPLY_ENABLED` 가드로 막혀 있다.
