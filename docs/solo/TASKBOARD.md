## 완료와 인계 규칙

상태는 미착수 / 진행중 / 검증중 / 완료 / 막힘 / 보류로 관리한다. 담당자가 관련 검증과 실제 동작을 확인하고 근거를 남기면 완료로 기록할 수 있다. 협업자가나 별도 사람의 검토자 칸을 반드시 채울 필요는 없다. AI 코드 검토는 실제 화면·파일·접수 관찰을 대신하지 않는다.

`tasks.json`과 이 Markdown은 자동 동기화되지 않는다. 작업 결과를 반영할 때 둘과 `../state/PROGRESS.md`, `../state/HANDOFF.md`를 함께 갱신한다. 날짜를 임의로 채우거나 과거 v0.8 업무표의 2인 계획을 그대로 적용하지 않는다.

```text
작업 ID / 완료한 사용자 동작:
변경 파일:
실행한 검증과 관찰 결과:
미실행·남은 제약:
다음 한 작업:
```
