# Chrome 확장(지원 실행기) 시작하기

2026-11-18 S05. `apps/extension/`은 Career Evidence 웹에서 승인한 지원서를 **개발용 자체 테스트 폼**(`http://127.0.0.1:4310/demo/apply/<공고>`)에 입력·첨부하고 접수 결과를 확인하는 MV3 확장이다. 실제 기업 채용사이트에는 동작하지 않는다. 설계·보장 범위는 [BROWSER_ADAPTERS](BROWSER_ADAPTERS.md), 내부 프로토콜은 [EXECUTOR_PROTOCOL](EXECUTOR_PROTOCOL.md).

## 수동 사용 절차

1. 프로젝트 루트에서 `npm run dev`(API·웹·worker).
2. Chrome `chrome://extensions` → 개발자 모드 → 압축해제된 확장 프로그램 로드 → `apps/extension` 선택.
3. 웹에서 이력서 확정 → 공고 검색 → 맞춤 편집 → 최종 제출본 확정·PDF 생성 → **지원 준비 시작**.
4. 지원 화면에서 문항 답변을 저장한다. **지원 이력** 화면에서 **확장 연결 코드 만들기**를 누른다.
5. 확장 아이콘으로 사이드 패널을 열고 코드를 입력해 연결한다.
6. 패널의 **지원 폼 열기** → **폼 확인·입력**: 답변 입력·PDF 첨부 후 다시 읽어 서버와 대조한다(제출하지 않음).
7. 웹 지원 화면에서 내용을 확인하고 **승인하고 제출**. 패널이 열려 있으면 같은 폼에 다시 확인한 뒤 한 번 제출하고, 사이트 접수 기록으로 결과를 확인한다.
8. 접수 여부가 불명이면 웹에서 **접수 결과 확인(재제출 아님)**을 누른다.

## 자동 검증

**기본은 제출 직전에서 멈춘다**(사용자 지시 2026-11-18): 연결 → 폼 입력·첨부·readback → 웹 승인 화면 표시까지만 하고 승인·제출은 누르지 않으며, 승인·시도·접수 0건을 DB로 확인한다. `--headful`은 Chrome 창을 띄워 단계 사이 1.5초 간격으로 보여 주고 끝 화면을 30초(`--hold=초`) 남긴다. 아래 전체 흐름은 `--submit-local`을 줄 때만 실행한다.

`node scripts/chrome-apply-e2e.mjs --submit-local`은 임시 DB로 개발 서버를 띄우고, 설치된 Google Chrome을 임시 프로필로 실행해 CDP로 확장을 올린 뒤 위 흐름(웹 클릭·연결 코드·입력·첨부·readback·승인·제출·접수 근거·입력 충돌·전송 중 강제 종료·재시작·접수 결과 확인·390px 화면)을 확인한다. 4310·4311 포트가 비어 있어야 한다. 사이드 패널은 사용자 클릭 없이 열 수 없어, 이 스크립트는 패널 대신 서비스 워커의 같은 실행 함수(`ceExecutor`)를 호출한다. 패널 화면·클릭 경로는 위 수동 절차로 확인한다.
