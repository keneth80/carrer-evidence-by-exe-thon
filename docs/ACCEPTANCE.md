# Career Evidence 인수 기준 v0.7

기준일: 2026.11.16 · **구현 후 실행할 인수 시나리오**

이 문서는 실행 결과가 아니다. 통합 자료 생성 시점에 신규 제품 흐름은 미구현 또는 미검증이며, 각 결과는 실제 실행 뒤 PASS / FAIL / BLOCKED / NOT_RUN으로 기록한다. 기존 foundation 검사나 새 계약의 형식 검증을 아래 제품 시나리오의 통과로 합산하지 않는다.

## 검증 기록 방법

실행한 케이스에는 환경, 코드 revision, 입력 fixture, 관찰 결과, 증거 위치를 남긴다. 실제 사용자 개인정보와 비밀 값은 증거 자료에 포함하지 않는다. 실패를 숨기기 위해 테스트를 삭제하거나 mock을 live로 바꾸어 표시하지 않는다.

형식·DB 제약 → 서비스 통합 → 자체 폼 브라우저 → 선택한 실제 사이트 검증을 구분한다. 자체 폼의 원자적 접수 보장은 외부 ATS의 접수 보장이 아니다. 관련 변경의 구체적인 위험을 확인한 뒤 다음 단계로 진행한다.

| R09 | 희망 조건 변경·늦은 검색 응답 | 해당 revision과 결과 연결; 저장 근거 재평가와 새 탐색 구분 |
