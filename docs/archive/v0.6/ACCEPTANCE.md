# 구현 후 확인할 시나리오

상태: **제안된 인수 기준, 이번 검토에서는 실행하지 않음.** 기존 v0.5의 26개 코드 테스트·61개 계약 테스트는 아래 새 기능을 검증하지 않는다.

| P08 | 자동지원한 공고에서 다시 유사 공고가 파생 | 승인된 기준을 자동 확대하거나 새 캠페인을 임의 생성하지 않는다. |

## 검증 층위

형식·DB 제약 → 서비스 통합 → 자체 폼 브라우저 → 지원할 실제 사이트의 허용된 검증 순으로 확인한다. 실제 기업 제출을 수행하지 않은 검증을 외부 접수 성공으로 기록하지 않는다. 사용자 실제 이력서·접수 화면·민감한 대화 내용을 공개 fixture나 데모 영상에 넣지 않는다.
