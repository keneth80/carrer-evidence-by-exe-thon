# 과거 자료

이 폴더는 변경 배경을 확인하기 위한 과거 사본이다. 현재 개발의 제품 범위·첫 과업·자동 지원 정책은 루트 `CLAUDE.md`, `DECISIONS.md`, `docs/PRODUCT_SPEC.md`, `contracts/v0.7/`을 따른다.

- v0.5: 처음 제공한 스타터 문서와 프롬프트. 원래 CLAUDE.md는 중첩 프로젝트 지침으로 로드되지 않도록 `CLAUDE.v0.5.reference.md`라는 이름으로 보관했다.
- v0.6: 이력서 중심 흐름을 정정한 검토 자료. 이번 통합본에는 요구사항이 이미 반영되어 있으므로 수정 패치처럼 다시 적용할 필요가 없다.

이전 문서의 synthetic-only·고정 검색어·단일 폼 데모 범위는 과거 구현 상태다. 실제 이력서와 대화형 편집·유사 공고 자동 지원을 제외하는 현재 요구사항이 아니다. 과거 검사 결과는 해당 버전의 범위를 검증한 기록이며 신규 기능의 완료 증거가 아니다.
