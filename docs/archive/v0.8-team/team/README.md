# 팀 협의 자료 v0.8

현재 제품·API 계약은 v0.7, 팀 공유 패키지는 v0.8이다. 실행 코드는 기존 기반이며 문서 준비를 제품 구현 완료로 표시하지 않는다.

## 권장 읽기 순서

> 공개 저장소에는 1~3번 파일(PDF·xlsx)을 넣지 않았다. 참여자 개인 이름이 들어 있어서다. 같은 내용의 편집 원고는 `PRODUCT_BRIEF.md`, `TEAM_WORKPLAN.md`, `tasks.json`에 있다.

1. `Career_Evidence_Team_Brief_v0.8.pdf`: 협업자에게 먼저 공유할 2페이지 기획서.
2. `Career_Evidence_Team_Workplan_v0.8.pdf`: 두 가지 분업안과 연결·검수·일정.
3. `Career_Evidence_Team_Taskboard_v0.8.xlsx`: 협업 방식, 실제 담당자와 상태를 정하는 업무표.
4. `TEAM_WORKPLAN.md`: 코드 소유 범위와 상세 인계 방법.

`PRODUCT_BRIEF.md`는 기획서의 편집 가능한 원고다. `tasks.json`은 최초 업무표를 만든 기준 데이터다. 업무표에서 실제 담당·상태를 바꾼 뒤 JSON으로 자동 동기화되지는 않으므로, 개발 인계 시 바뀐 결정과 상태를 `DECISIONS.md`, `docs/state/`에 함께 기록한다.

협업자의 이름·개발 분야·가용시간이 아직 미확인이다. 제안 역할과 목표일을 회의 없이 확정 배정으로 취급하지 않는다. 외부 연락·계정 초대·실제 회사 지원·일정 알림은 이 자료 작성으로 실행되지 않는다.
