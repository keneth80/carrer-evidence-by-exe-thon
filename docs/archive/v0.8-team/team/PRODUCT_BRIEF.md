# Career Evidence — 팀 공유 기획서 v0.8

내 이력서에서 시작해, 지원 완료까지 이어지는 AI 채용 에이전트

v0.8 · 2026.11.16 · 제품·API 기준 v0.7 / 팀 공유·업무 협의용

보유 이력서로 공고를 찾고, AI와 대화하며 제출 서류를 다듬고, 브라우저 지원과 지원 이력을 연결합니다. 구직자의 반복 준비 부담을 줄이는 2인 팀 프로젝트입니다.

## 한 번 준비한 경험이 다음 지원으로 이어집니다

### 01 누구의 어떤 일을 돕나

초기 대상은 이력서를 가진 경력 구직자입니다. 공고마다 경험을 다시 정리하고 같은 정보를 반복 입력하는 일을 줄입니다. 추천 이유와 미확인 조건을 보여주며, 합격 확률이나 채용 성과를 보장하지 않습니다.

### 02 제품의 전체 흐름

| 단계 | 사용자가 얻는 결과 |
| --- | --- |
| 1. 이력서 등록·확인 | 텍스트 PDF 또는 붙여넣기에서 경력을 추출하고 사용자가 정정·확정합니다. 원본과 경력 근거를 보존합니다. |
| 2. 이력서 기반 공고 추천 | 확정 경력과 희망 조건으로 Liner 검색을 수행합니다. 추천 이유·요건 차이·출처를 연결합니다. |
| 3. 공고 선택·AI 대화 수정 | AI의 질문에 경험을 설명하면 실제 문서 변경안을 만듭니다. 변경 비교를 보고 수용·수정합니다. |
| 4. 제출본 확정·브라우저 지원 | 공고별 PDF와 답변을 확정하고 Chrome 또는 Ego 실행기로 입력·첨부·제출합니다. |
| 5. 지원 이력 관리 | 지원 당시 공고·제출 파일·답변·접수 근거를 보관합니다. 접수 상태와 면접 등 채용 단계를 구분합니다. |
| 6. 유사 공고·자동 지원 | 선택한 지원을 기준으로 유사 공고를 찾습니다. 추천·자동 준비·조건부 자동 제출 중 선택합니다. |

### 03 이력서의 사실과 사용자의 의사를 지킵니다

- 원본·확정 경력·공고별 제출본을 구분합니다. 없는 기술·담당 업무·성과 수치를 만들지 않습니다.
- 확정 PDF를 재사용하거나, 허용된 사실 안에서 공고별로 수정합니다. 자동 지원 조건·사이트·계정·건수·기간은 사용자가 정합니다.
- 정책 범위 안에서는 매건 확인 없이 제출합니다. 새 답변이 필요하면 검토 대기, 접수가 불명확하면 자동 재제출을 멈춥니다.

### 04 Liner·편집 AI·브라우저의 역할

개발 도구는 Claude Code입니다. 사용자용 AI 대화와 브라우저 실행 기능은 제품 안에 구현합니다.

| 구성 | 제품에서 맡는 일 |
| --- | --- |
| Liner [1] | 공고 탐색과 요구사항·출처 조사. 기업 심층 조사는 선택 기능입니다. |
| 이력서 편집 AI | 확인된 경험과 공고를 바탕으로 대화·변경안을 생성합니다. 제품용 모델/API는 별도 선택·검증합니다. |
| Chrome / Ego [2][3] | 확정한 자료로 지원하고 결과를 관측합니다. 첫 경로는 기존 Chrome 골격과 자체 폼으로 구현합니다. |

## 공동 목표는 한 사용자 흐름의 완주입니다

### 05 현재 준비 상태와 구현 범위

통합 기획·화면·API/DB 계약과 React·TypeScript·Node·SQLite 기초 코드가 준비돼 있습니다. 이력서 등록부터 대화형 편집·지원까지의 제품 연결은 앞으로 구현할 대상입니다.

| 우선순위 | 검증할 범위 |
| --- | --- |
| 첫 완주 | 실제 업로드 경로 → 경력 기반 검색 → 대화·PDF → Chrome 자체 폼 지원 → 제출본 재열람 |
| 자동화 연결 | 고정 기준의 유사 공고·자동 준비, 이어서 정책·한도·중지·접수 불명을 갖춘 자동 제출 |
| 후속 확장 | 검증한 실제 채용사이트, Ego 실행 채널, DOCX/OCR, 선택적 이메일 연동 |

공개 시연에는 합성 이력서를 실제 입력 경로로 넣습니다. 자체 폼 접수를 외부 기업 지원으로 표현하지 않으며, 구현한 기능과 계획을 구분합니다.

### 06 2인 팀 업무 분장 협의안

| 담당 | 개발을 나누는 경우의 제안 |
| --- | --- |
| 개발자 | 제품·웹 화면, 대화형 편집·PDF, Chrome 실행기, 사용자 흐름 통합 |
| 팀원(협업자) | API·DB·이력서 추출, Liner 검색·작업 실행기, 지원 권한·이력 저장 |
| 공동 | 입출력 계약·자동 지원 기준, 통합 검수, 발표·최종 제출 확인 |

협업자의 전문 분야·가용시간은 미확인입니다. 개발+검수안에서는 개발자가 핵심 개발, 협업자가 공고 정답표·AI 수정 검수·사용성 테스트·발표 자료를 맡습니다. 상세 업무표에서 담당·검토자·목표일을 확정합니다.

가용시간 확인 전의 목표 일정입니다. API·DB 작업에 병목이 생기면 독립 모듈을 재배분하고, 여러 사이트·추가 문서 형식 확장부터 늦춥니다. 각 작업은 책임자 1명·검토자 1명을 정하고 변경 결정을 DECISIONS.md에 남깁니다.

### 08 완료 판단과 제출 준비

경력이 다른 이력서에서 검색 계획이 달라지는지, 대화가 실제 문서에 반영되는지, 제출 파일과 접수 근거가 이력에서 다시 열리는지 확인합니다. 준비 시간·수정량·오류를 측정하며 실측 전 개선율을 성과로 쓰지 않습니다.

기존 제공 안내 기준: 11/25 23:59 마감, 소스코드·5분 이내 영상·1~2페이지 PDF. 최신 공식 안내는 제출 담당이 다시 확인합니다. 기존 기반과 새 개발분, 실제 Liner 호출·저장 결과·미구현 기능을 구분해 설명합니다.
