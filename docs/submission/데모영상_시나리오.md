# 데모 영상 시나리오 (완성본 3분 10초, `데모영상.mp4`, 2026-11-21 세 번째 녹화)

이력서는 합성 이력서만 씁니다(실제 인물·실제 이력서·연락처는 화면에 나오지 않음, 새 데모 DB). 공고는 Liner Web Search로 찾은 **실제 공개 채용 공고**이고(사용자 결정 2026-11-21), HR 전문가 점검·JD 맞춤은 Liner Router API 실호출입니다.

## 찍기 전 확인

- 새 데모 DB(합성 자료만), 프로필 이름은 '데모 사용자'
- 브라우저 탭·주소창·다른 창에 개인 정보가 보이지 않게 브라우저 화면만 녹화
- `CHAT_MODE=liner`는 호출 한도를 명령줄로 묶어서 실행(`LINER_CHAT_MAX_CALLS`, `LINER_CHAT_BUDGET_MICRO_USD`), 검색은 `LINER_MODE=mock`
- 제출 버튼은 누르지 않는다

## 만든 방법(완성본, 2026-11-21 세 번째 녹화)

- 합성 Word 이력서 + 실제 검색. Liner Router chat 8건·Web Search 7건 모두 성공(확인 비용 약 $0.21). 공고는 요약에 실제 공고 내용이 있고 회사 이름을 읽은 것을 스크립트가 고른다.
- ego 브라우저 화면만 캡처(1280×800)해 ffmpeg로 묶었다. 응답을 기다리는 구간만 8배속(자막에 표시). 편집 없음.
- 리허설 1회(실제 검색 + mock 대화) 뒤 실호출 3회: 앞의 두 번은 고른 공고의 요약에 자격 요건이 없어(홍보 문구, 다른 공고 목록) 점검표가 비어 폐기.
- 실제 공고는 자체 테스트 폼 지원 대상이 아니므로 지원 준비 화면은 찍지 않고 확정 PDF에서 멈춘다.
- 이전 영상: `데모영상_v2_합성공고.mp4`(합성 공고, 3분 15초), `데모영상_이전.mp4`(2분 50초). 영상 파일은 저장소에 넣지 않는다(`.gitignore`).
