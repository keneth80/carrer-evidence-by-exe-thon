## 찍기 전 확인

- 새 데모 DB(합성 자료만), 프로필 이름은 '데모 사용자'
- 브라우저 탭·주소창·다른 창에 개인 정보가 보이지 않게 브라우저 화면만 녹화
- `CHAT_MODE=liner`는 호출 한도를 명령줄로 묶어서 실행(`LINER_CHAT_MAX_CALLS`, `LINER_CHAT_BUDGET_MICRO_USD`), 검색은 `LINER_MODE=mock`
- 제출 버튼은 누르지 않는다

## 만든 방법(완성본)

- 합성 자료만 든 빈 DB, Liner Router chat 실호출 7건(확인 비용 약 $0.10, 전송 불명 0), 공고 검색은 합성 공고(mock).
- ego 브라우저 화면만 캡처(1280×800)해 ffmpeg로 묶었다. 다른 창·주소창은 찍히지 않는다. Liner 응답을 기다리는 구간만 5배속으로 돌리고 자막에 '▶▶ 5배속'을 표시했다.
- 편집 없음(녹화 그대로). AI 답변 문장에 내부 ID가 나오지 않는 것을 DB 기록으로 확인(턴 결과 5개, 0건).
- 영상 파일은 YouTube에 올리고 저장소에는 넣지 않는다(`.gitignore`).
- 제출 버튼은 누르지 않았다(Chrome 확장 단계 직전에서 멈춤).
