## 찍기 전 확인

- 새 데모 DB(합성 자료만), 프로필 이름은 '데모 사용자'
- 브라우저 탭·주소창·다른 창에 개인 정보가 보이지 않게 브라우저 화면만 녹화
- `CHAT_MODE=liner`는 호출 한도를 명령줄로 묶어서 실행(`LINER_CHAT_MAX_CALLS`, `LINER_CHAT_BUDGET_MICRO_USD`), 검색은 `LINER_MODE=mock`
- 제출 버튼은 누르지 않는다

## 만든 방법(완성본, 2026-11-21)

- 합성 자료만 든 빈 DB(합성 Word 이력서, 합성 공고와 합성 공고 본문), Liner Router chat 실호출 8건 모두 성공(확인 비용 약 $0.26, 전송 불명 0), 공고 검색은 합성 공고(mock).
- ego 브라우저 화면만 캡처(1280×800)해 ffmpeg로 묶었다. 다른 창·주소창은 찍히지 않는다. Liner 응답을 기다리는 구간만 8배속으로 돌리고 자막에 '▶▶ 8배속'을 표시했다.
- 편집 없음(녹화 그대로). mock 리허설 3회로 화면이 잡히는지 확인한 뒤 실호출로 찍었다(첫 실호출 녹화본은 점검표가 대화 칸 안쪽 스크롤에 가려 폐기, 8건·약 $0.27).
- 이전 영상(2분 50초)은 `데모영상_이전.mp4`로 남겼다. 영상 파일은 저장소에 넣지 않는다(`.gitignore`).
